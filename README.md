# Take-home tasks

## Variant A — Gut Run

From the repository root, run `python -m http.server 8000` and open [Gut Run](http://localhost:8000/variant-a-game/).

Tap to start and jump. Space and ↑ also jump during play. Clear all 15 obstacles to win. On the fail screen, **Nochmal spielen** returns you to the start screen with a freshly shuffled course. Tap when you're ready for another run.
